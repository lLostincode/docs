---
title: 'List Sessions'
openapi: 'GET /api/v1/sessions/'
---

Retrieve sessions for your account. By default, sessions with zero messages are excluded.

<ParamField query="agent_id" type="string">
  Filter to sessions created from a specific agent (by agent UUID).
</ParamField>

<ParamField query="has_messages" type="boolean" default="true">
  When `true` (the default), sessions with no messages yet are excluded. Pass `false` to include them.
</ParamField>

<CodeGroup>
```bash cURL
curl -X GET https://api-be.atthene.com/api/v1/sessions/ \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api-be.atthene.com/api/v1/sessions/",
    headers={"x-api-key": "YOUR_API_KEY"}
)
sessions = response.json()
```

```javascript JavaScript
const response = await fetch('https://api-be.atthene.com/api/v1/sessions/', {
  headers: {
    'x-api-key': 'YOUR_API_KEY'
  }
});
const sessions = await response.json();
```
</CodeGroup>

## Response

Returns an array of session summaries (no `config_hash` - that's only present on create):

```json
[
  {
    "session_id": "session_abc123",
    "title": "Support Session",
    "status": "active",
    "created_at": "2025-01-15T10:30:00Z",
    "last_execution": "2025-01-15T10:32:00Z",
    "message_count": 4,
    "is_scheduled": false,
    "schedule_id": null
  }
]
```
