---
title: 'Get Session'
openapi: 'GET /api/v1/sessions/{session_id}/'
---

Retrieve a session's details together with a page of its message history and artifacts (cursor-paginated, newest messages first internally, returned oldest-to-newest).

<ParamField path="session_id" type="string" required>
  The session ID
</ParamField>

<ParamField query="limit" type="integer" default="10">
  Number of messages to return, 1-50.
</ParamField>

<ParamField query="before" type="string">
  Cursor for pagination - pass the `next_cursor` value from a previous response (a `msg_<uuid>` string) to fetch older messages.
</ParamField>

<CodeGroup>
```bash cURL
curl -X GET https://api-be.atthene.com/api/v1/sessions/session_abc123/ \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api-be.atthene.com/api/v1/sessions/session_abc123/",
    headers={"x-api-key": "YOUR_API_KEY"}
)
session = response.json()
```

```javascript JavaScript
const response = await fetch('https://api-be.atthene.com/api/v1/sessions/session_abc123/', {
  headers: {
    'x-api-key': 'YOUR_API_KEY'
  }
});
const session = await response.json();
```
</CodeGroup>

## Response

```json
{
  "id": "session_abc123",
  "object": "agent.session",
  "status": "active",
  "title": "Support Session",
  "created_at": "2025-01-15T10:30:00Z",
  "config": {},
  "metadata": {},
  "messages": [
    {
      "id": "msg_1a2b3c4d",
      "role": "user",
      "content": "How can I reset my password?",
      "agentName": null,
      "run_id": null,
      "tool_calls": null,
      "attachments": [],
      "created_at": 1736937000
    }
  ],
  "artifacts": [],
  "has_more": false,
  "next_cursor": null
}
```

<Note>
`config` and `metadata` come from the session's stored `agent_config` / `api_metadata` - they may be empty objects depending on how the session was created. There is no top-level `config_hash` on this response (that's only returned when a session is created).
</Note>
