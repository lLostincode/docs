---
title: 'Create Session'
openapi: 'POST /api/v1/sessions/'
---

Create a new session by sending a complete multi-agent system configuration directly (no saved agent required). Sessions represent individual conversation instances.

## Request Body

Send the complete system configuration as the request body (JSON), using the same shape as a [YAML Configuration](/guides/yaml-configuration) system config: top-level `name`, `entry_point`, an `agents` array, and `edges`.

<CodeGroup>
```bash cURL
curl -X POST https://api-be.atthene.com/api/v1/sessions/ \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Support Session",
    "entry_point": "support_agent",
    "agents": [
      {
        "name": "support_agent",
        "agent_type": "llm_agent",
        "system_prompt": "You are a helpful customer support agent.",
        "llm_config": {
          "model": "gpt-4o",
          "temperature": 0.7
        },
        "tools": ["tavily_search"]
      }
    ],
    "edges": [
      {"from": "__start__", "to": "support_agent"},
      {"from": "support_agent", "to": "__end__"}
    ]
  }'
```

```python Python
import requests

config = {
    "name": "Support Session",
    "entry_point": "support_agent",
    "agents": [
        {
            "name": "support_agent",
            "agent_type": "llm_agent",
            "system_prompt": "You are a helpful customer support agent.",
            "llm_config": {
                "model": "gpt-4o",
                "temperature": 0.7
            },
            "tools": ["tavily_search"]
        }
    ],
    "edges": [
        {"from": "__start__", "to": "support_agent"},
        {"from": "support_agent", "to": "__end__"}
    ]
}

response = requests.post(
    "https://api-be.atthene.com/api/v1/sessions/",
    headers={"x-api-key": "YOUR_API_KEY"},
    json=config
)
session = response.json()
```

```javascript JavaScript
const config = {
  name: "Support Session",
  entry_point: "support_agent",
  agents: [
    {
      name: "support_agent",
      agent_type: "llm_agent",
      system_prompt: "You are a helpful customer support agent.",
      llm_config: {
        model: "gpt-4o",
        temperature: 0.7
      },
      tools: ["tavily_search"]
    }
  ],
  edges: [
    { from: "__start__", to: "support_agent" },
    { from: "support_agent", to: "__end__" }
  ]
};

const response = await fetch('https://api-be.atthene.com/api/v1/sessions/', {
  method: 'POST',
  headers: {
    'x-api-key': 'YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(config)
});

const session = await response.json();
```
</CodeGroup>

## Response

```json
{
  "success": true,
  "session_id": "session_abc123",
  "config_hash": "a1b2c3d4e5f6"
}
```

<Note>
The returned `session_id` is used for all runtime operations with this session.
</Note>
