---
title: 'List Versions'
openapi: 'GET /api/v1/agent/{id}/versions/'
---

List the versions of an agent, newest first. The list holds no configuration; read one with [Get Version](/api-reference/agents/get-version).

<ParamField path="id" type="string" required>
  The UUID of the agent.
</ParamField>

<CodeGroup>
```bash cURL
curl -X GET https://api.artaios.ai/api/v1/agent/{id}/versions/ \
  -H "x-api-key: YOUR_API_KEY"
```
</CodeGroup>
