---
title: 'List Agents'
openapi: 'GET /api/v1/agent/'
---

Retrieve all agent configurations for the authenticated user. This endpoint returns a paginated list of the agents you have access to, including their metadata and configuration details.

<CodeGroup>
```bash cURL
curl -X GET https://api.artaios.ai/api/v1/agent/ \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api.artaios.ai/api/v1/agent/",
    headers={"x-api-key": "YOUR_API_KEY"}
)
agents = response.json()["results"]
```

```javascript JavaScript
const response = await fetch('https://api.artaios.ai/api/v1/agent/', {
  headers: {
    'x-api-key': 'YOUR_API_KEY'
  }
});
const { results: agents } = await response.json();
```
</CodeGroup>

## Pagination

The response is not a bare array. Each page holds up to 20 agents by default.

- `count` - Total number of agents across all pages
- `next` - URL of the next page, or `null` on the last page
- `previous` - URL of the previous page, or `null` on the first page
- `results` - The agents on this page

Use `?page=N` to select a page and `?page_size=N` to change the page size (maximum 100). Follow `next` until it is `null` to retrieve every agent.

```bash
curl -X GET "https://api.artaios.ai/api/v1/agent/?page=2&page_size=50" \
  -H "x-api-key: YOUR_API_KEY"
```

<Note>
**Key Response Fields:**
- `agent_key` - Unique identifier derived from agent name
- `version_number` - Current version of the agent configuration
- `config_hash` - Hash of the current configuration for change detection
- `workspace`, `workspace_name`, `workspace_kind` - The workspace the agent lives in

The list does **not** include `system_config`. Fetch it with [Get Current Version](/api-reference/agents/current-version).
</Note>
