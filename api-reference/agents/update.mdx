---
title: 'Update Agent'
openapi: 'PATCH /api/v1/agent/{id}/'
---

Update an existing agent configuration.

<Warning>
`system_config` is replaced wholesale, not deep-merged. Sending only a partial object (e.g. just `llm_config`) discards the rest of the previous configuration. Always send the **complete** `system_config` - same shape as [Create Agent](/api-reference/agents/create) - with your changes applied on top of the current version, which you can read via `GET /api/v1/agent/{id}/versions/current/`.
</Warning>

Each update creates a new immutable version (`version_number` auto-increments, e.g. `v1` -> `v2`) and recomputes `config_hash`; it doesn't edit the previous version in place.

<ParamField path="id" type="string" required>
  The agent ID
</ParamField>

## Request Body

<ParamField body="system_config" type="object" required>
  Complete, updated system configuration object (same schema as [Create Agent](/api-reference/agents/create) and [YAML Configuration](/guides/yaml-configuration))
</ParamField>

## Response

Returns the agent's metadata with the bumped `version_number` and new `config_hash`/`updated_at`. `system_config` is write-only and is **not** included - see [Get Agent](/api-reference/agents/get).
