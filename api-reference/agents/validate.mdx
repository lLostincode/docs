---
title: 'Validate Agent'
openapi: 'POST /api/v1/agent/validate/'
---

Validate an agent configuration without creating it. This is useful for testing configurations before deployment.

## Request Body

Send the complete system configuration - the same shape as `system_config` in [Create Agent](/api-reference/agents/create) and in [YAML Configuration](/guides/yaml-configuration) - as the raw request body (do **not** wrap it in a `system_config` key here).

<CodeGroup>
```bash cURL
curl -X POST https://api-be.atthene.com/api/v1/agent/validate/ \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Test Agent",
    "description": "A test agent",
    "entry_point": "assistant",
    "agents": [
      {
        "name": "assistant",
        "agent_type": "llm_agent",
        "system_prompt": "You are a helpful assistant.",
        "llm_config": {
          "model": "gpt-4o",
          "temperature": 0.7
        }
      }
    ],
    "edges": [
      {"from": "__start__", "to": "assistant"},
      {"from": "assistant", "to": "__end__"}
    ]
  }'
```

```python Python
import requests

config = {
    "name": "Test Agent",
    "description": "A test agent",
    "entry_point": "assistant",
    "agents": [
        {
            "name": "assistant",
            "agent_type": "llm_agent",
            "system_prompt": "You are a helpful assistant.",
            "llm_config": {
                "model": "gpt-4o",
                "temperature": 0.7
            }
        }
    ],
    "edges": [
        {"from": "__start__", "to": "assistant"},
        {"from": "assistant", "to": "__end__"}
    ]
}

response = requests.post(
    "https://api-be.atthene.com/api/v1/agent/validate/",
    headers={"x-api-key": "YOUR_API_KEY"},
    json=config
)
validation_result = response.json()
```

</CodeGroup>

## Response

<ResponseField name="valid" type="boolean">
  Whether the configuration is valid
</ResponseField>

<ResponseField name="message" type="string">
  Human-readable summary, e.g. `"Configuration is valid"` or `"Invalid configuration"`
</ResponseField>

<ResponseField name="warnings" type="array">
  List of `{"message": string}` objects for non-fatal issues
</ResponseField>

<ResponseField name="errors" type="array">
  List of `{"message": string}` objects describing what's invalid
</ResponseField>

<ResponseField name="suggestions" type="array">
  List of `{"message": string}` objects with suggested fixes, when available
</ResponseField>

### Valid Configuration
```json
{
  "valid": true,
  "message": "Configuration is valid",
  "warnings": [],
  "errors": [],
  "suggestions": []
}
```

### Invalid Configuration
```json
{
  "valid": false,
  "message": "Invalid configuration",
  "warnings": [],
  "errors": [
    {
      "message": "Unsupported model specified for 'llm_config.model'"
    }
  ],
  "suggestions": []
}
```

<Tip>
Always validate your agent configurations before deploying them to production to catch configuration errors early.
</Tip>
