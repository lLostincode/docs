---
title: 'Create Agent'
openapi: 'POST /api/v1/agent/'
---

Create a new agent configuration. The full configuration must be provided within the `system_config` object, using the same shape as a [YAML Configuration](/guides/yaml-configuration) system config (JSON-encoded). The top-level `name` field inside `system_config` is required.

<Note>
`system_config` is **write-only** - it's accepted on create, but not echoed back in the response. Read it back via `GET /api/v1/agent/{id}/versions/current/`.
</Note>

## Request Body

<ParamField body="system_config" type="object" required>
  Complete system configuration object (same schema as a YAML config file, JSON-encoded)

  <Expandable title="system_config Properties">
    <ParamField body="name" type="string" required>
      System/agent name
    </ParamField>

    <ParamField body="description" type="string" required>
      Description of what this agent does
    </ParamField>

    <ParamField body="entry_point" type="string" required>
      Name of the agent (from `agents`) that receives the initial input
    </ParamField>

    <ParamField body="agents" type="array" required>
      List of agent definitions. Each entry needs at least `name` and `agent_type` (e.g. `llm_agent`), plus `system_prompt`, `llm_config`, `tools`, and `knowledge_bases` as needed - see [Agent Configuration](/guides/yaml-configuration#agent-configuration).
    </ParamField>

    <ParamField body="edges" type="array">
      Workflow edges connecting agents (required when `architecture` is `workflow`, the default). See [Workflow Edges](/guides/yaml-configuration#workflow-edges).
    </ParamField>
  </Expandable>
</ParamField>

<CodeGroup>
```bash cURL
curl -X POST https://api-be.atthene.com/api/v1/agent/ \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "system_config": {
      "name": "Support Agent",
      "description": "Answers customer support questions",
      "entry_point": "support_agent",
      "agents": [
        {
          "name": "support_agent",
          "agent_type": "llm_agent",
          "system_prompt": "You are a helpful customer support agent.",
          "llm_config": {
            "model": "gpt-4o",
            "temperature": 0.7
          }
        }
      ],
      "edges": [
        {"from": "__start__", "to": "support_agent"},
        {"from": "support_agent", "to": "__end__"}
      ]
    }
  }'
```

```python Python
import requests

data = {
    "system_config": {
        "name": "Support Agent",
        "description": "Answers customer support questions",
        "entry_point": "support_agent",
        "agents": [
            {
                "name": "support_agent",
                "agent_type": "llm_agent",
                "system_prompt": "You are a helpful customer support agent.",
                "llm_config": {
                    "model": "gpt-4o",
                    "temperature": 0.7
                }
            }
        ],
        "edges": [
            {"from": "__start__", "to": "support_agent"},
            {"from": "support_agent", "to": "__end__"}
        ]
    }
}

response = requests.post(
    "https://api-be.atthene.com/api/v1/agent/",
    headers={"x-api-key": "YOUR_API_KEY"},
    json=data
)
agent = response.json()
```
