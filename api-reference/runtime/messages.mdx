---
title: 'Get Messages'
openapi: 'GET /api/v1/runtime/{session_id}/messages/'
---

Retrieve all messages for a session (no pagination - the full history is returned in one call).

<ParamField path="session_id" type="string" required>
  The session ID
</ParamField>

<CodeGroup>
```bash cURL
curl -X GET https://api-be.atthene.com/api/v1/runtime/session_abc123/messages/ \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api-be.atthene.com/api/v1/runtime/session_abc123/messages/",
    headers={"x-api-key": "YOUR_API_KEY"}
)
messages = response.json()
```

```javascript JavaScript
const response = await fetch('https://api-be.atthene.com/api/v1/runtime/session_abc123/messages/', {
  headers: {
    'x-api-key': 'YOUR_API_KEY'
  }
});
const messages = await response.json();
```
</CodeGroup>
