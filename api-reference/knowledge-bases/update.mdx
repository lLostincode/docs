---
title: 'Update Knowledge Base'
openapi: 'PATCH /api/v1/knowledge-bases/{kb_id}/'
---

Modify knowledge base settings. Note that `description` is **not** an updatable field on this endpoint - only the fields below are accepted.

<ParamField path="kb_id" type="string" required>
  The knowledge base ID
</ParamField>

## Request Body

<ParamField body="name" type="string">
  Updated knowledge base name
</ParamField>

<ParamField body="datasources" type="array">
  Replace the set of datasource IDs directly attached to this knowledge base
</ParamField>

<ParamField body="chunking_strategy" type="object">
  Updated chunking configuration
</ParamField>

<ParamField body="llm_config" type="object">
  Updated LLM configuration used for retrieval-augmented generation
</ParamField>

<ParamField body="embedding_config" type="object">
  Updated embedding configuration
</ParamField>

<ParamField body="processing_metadata" type="object">
  Updated processing metadata
</ParamField>

<CodeGroup>
```bash cURL
curl -X PATCH https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/ \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Product Knowledge Base"
  }'
```

```python Python
import requests

data = {
    "name": "Updated Product Knowledge Base"
}

response = requests.patch(
    "https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/",
    headers={"x-api-key": "YOUR_API_KEY"},
    json=data
)
```

```javascript JavaScript
const data = {
  name: "Updated Product Knowledge Base"
};

const response = await fetch('https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/', {
  method: 'PATCH',
  headers: {
    'x-api-key': 'YOUR_API_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify(data)
});
```
</CodeGroup>

## Response

Returns the updated knowledge base object with new `updated_at` timestamp.
