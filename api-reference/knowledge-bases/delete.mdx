---
title: 'Delete Knowledge Base'
openapi: 'DELETE /api/v1/knowledge-bases/{kb_id}/'
---

Remove a knowledge base and all its indexed content.

<ParamField path="kb_id" type="string" required>
  The knowledge base ID
</ParamField>

<CodeGroup>
```bash cURL
curl -X DELETE https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/ \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.delete(
    "https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/",
    headers={"x-api-key": "YOUR_API_KEY"}
)
```

```javascript JavaScript
const response = await fetch('https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/', {
  method: 'DELETE',
  headers: {
    'x-api-key': 'YOUR_API_KEY'
  }
});
```
</CodeGroup>

## Response

Returns `200 OK` (not `204 No Content`) with a confirmation body:

```json
{
  "success": true,
  "message": "Knowledge base 'Product Knowledge Base' and associated resources deleted successfully"
}
```

<Warning>
This cascades further than just the knowledge base: it also deletes every retrieval method linked to it, and deletes the collection that was created alongside it (if the knowledge base was made via quick-create with `save_as_collection`). Datasources/files that existed independently of that auto-created collection are not deleted.
</Warning>
