---
title: 'Check Knowledge Base Status'
openapi: 'GET /api/v1/knowledge-bases/{id}/check_status/'
---

Poll the current status of a knowledge base during background ingestion. Returns the same representation as [Get Knowledge Base](/api-reference/knowledge-bases/get), fetched fresh.

<ParamField path="id" type="string" required>
  The knowledge base ID
</ParamField>

<CodeGroup>
```bash cURL
curl -X GET https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/check_status/ \
  -H "x-api-key: YOUR_API_KEY"
```

```python Python
import requests

response = requests.get(
    "https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/check_status/",
    headers={"x-api-key": "YOUR_API_KEY"}
)
status = response.json()
```

```javascript JavaScript
const response = await fetch('https://api-be.atthene.com/api/v1/knowledge-bases/kb_123/check_status/', {
  headers: {
    'x-api-key': 'YOUR_API_KEY'
  }
});
const status = await response.json();
```
</CodeGroup>
