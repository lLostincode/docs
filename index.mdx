## Welcome

Artaios agents are built with the Agent Builder in Artaios, or in Agent Studio
at [amas.artaios.com](https://amas.artaios.com). Once an agent is deployed, you
can use it from your own software, embed it on your website, or let colleagues
chat with it in Artaios.

## Where do I start?

<Steps>
  <Step title="Build and deploy an agent">
    Create an agent in the Agent Builder or Agent Studio and deploy a version.
  </Step>
  <Step title="Create an API key">
    Generate a key under **Settings** and note your agent's key.
  </Step>
  <Step title="Pick an integration">
    Call the agent over [REST](/documentation/integration/rest-api-tutorial),
    stream it over [WebSocket](/documentation/integration/websocket-api), or
    [embed the chatbot](/documentation/integration/chatbot-integration).
  </Step>
</Steps>

## Hosting and data

Artaios runs on **German cloud infrastructure** (Open Telekom Cloud) operated by
arttac solutions, ensuring data sovereignty and compliance with European
regulations.

## Want to go deeper? AMAS

Every Artaios agent runs on **AMAS**, the Artaios Multi Agent System: a YAML
execution runtime that supports workflow and supervisor patterns. You do not
need to know anything about it to build or integrate agents. If you want full
control over how an agent is configured, the **AMAS** section documents the
YAML format, agent types, multi-agent patterns and more.
